The exact prompt to build this yourself

Open ChatGPT, click the plus button, turn on Canvas, paste this in, and press return:

Make a fun, beautiful game called Snake, a modern version of the classic Snake game. Start by making the standard game. This should be in one HTML block using CSS, Javascript and other embedded elements that will make something beautiful. Ensure that it loads quickly and works smoothly on both desktop and mobile devices.

If Canvas doesn't appear after a minute or two, refresh and try again. Once it's finished, click Preview (top right) to play.

Making a website next (two-chat method)

Chat One — use Act–Explain–Please to develop the framework: "Act as a web designer with a strong understanding of beautiful web design aesthetics. I'm creating a website for [your business] — please give me three ideas for how to approach this effectively." Keep going until you have a clear framework.

Chat Two — turn on Canvas and paste: "Make a beautiful website based on the following framework: [paste your framework]. This should be in one HTML block using CSS, Javascript and other embedded elements that will make something beautiful."

To add images, sounds or video: save them in the same folder as your site and tell ChatGPT the exact filenames — e.g. "hero.jpg, 1920×1080". Download the HTML file each time to view embedded media.

Dashboard BWhich image tool?

ChatGPT, Midjourney, or Gemini Flash?

Different image generators have different strengths. Effective prompts specify subject, style, colour palette and aspect ratio — regardless of the tool.

Simple prompt vs refined prompt
Simple prompt

"Create an image of people working together in an office."

Refined prompt

"Create a minimalist infographic showing teamwork in a professional services firm. Corporate palette (blue, grey, white), 16:9 ratio, flat icons, clean modern style."

ReflectionWhen not to use AI

A helpful guiding question

Would I trust this answer if my reputation depended on it? AI isn't appropriate for every situation.

Confidential or personal data
Anything you wouldn't post publicly (see the CEO Test in Module 2).
Ethical or legal decisions
AI has no moral understanding — the judgement has to be human.
Strategic decisions
Anything requiring real human judgement, not just a fluent summary.

Key takeaways

You can build real things. Stunning visuals, working apps and websites — no coding background required.
Hallucinations are inevitable. Verification is essential, especially for anything client-facing.
Different tools, different strengths. Match the tool to the job — ChatGPT, Midjourney, Gemini Flash.
You are the conductor; AI is the orchestra. Direction and judgement stay with you.
