Framework

Act – Explain – Please

Assign a role, give context, then make a clear, specific request. The default framework for this course — see Module 1's live builder.

Framework

RACE · CARE · APE · CREATE · RISE

Five alternative frameworks for when Act–Explain–Please isn't quite enough structure — each emphasises clarity, audience or step-by-step reasoning.

Safe practice

The CEO Test / The Me Test

Would I be comfortable if this prompt and its output were posted publicly? Would I be comfortable if this was my own data being shared like this?
