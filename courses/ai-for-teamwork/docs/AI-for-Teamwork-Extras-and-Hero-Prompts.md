# AI for Teamwork — Fun Extras Banners & Epic Hero Prompts

Two sets: **four epic hero options** for the course masthead (built to animate into video — no people, so they sidestep casting entirely), and **16 banner images**, one per fun-extra game.

**On the ethnicity criteria:** nearly every prompt below is deliberately people-free — object still lifes and epic nature/abstract scenes carry no casting at all, which is the cleanest way to meet the requirement. The handful of prompts that include hands or distant figures specify diverse representation explicitly, and the review rule from the diversity set still applies: re-roll anything Midjourney drifts toward stereotype or that renders incidental background figures as a single demographic.

## Part 1 — The epic hero (for video)

Four options for the main course hub masthead. All are built from **layered depth, directional flow and one strong motion idea**, so they'll animate beautifully in Midjourney video / Runway / Kling. Each carries the brand's teal accent in the light or environment, and none features people.

Generate at `--ar 21:9` for the site masthead; run a second pass at `--ar 16:9` for the video tools (or outpaint the 21:9). Keep `--style raw --v 7`.

## Workflow notes

1. **Heroes first:** run all four, pick the one that grades best against the site's dark masthead overlay. `--sref` the winner if you want the runner-up as a matching secondary. For video, feed the still into Midjourney video / Runway / Kling with the motion note as the animation prompt; export a 10–20s loop, compress to web-weight MP4, and it can drop into the hub's existing `.hero-media` slot as a `<video autoplay muted loop>` (the site's reduced-motion handling already covers it — one line of markup to swap when you're ready).
2. **Banners:** save over the `x*.jpg` filenames above into `assets/media/pics/` — the extras build (Phase E1) will reference exactly those names. Compress to ~150–250KB; they display small.
3. **"No readable text" matters** on x2a, x4a, x7b and x8b — Midjourney text artifacts are the most likely re-roll reason in this set.
4. The two prompts with hands specify skin tone; everything else is people-free. If MJ adds uninvited background figures anywhere, re-roll or `--no people`.
