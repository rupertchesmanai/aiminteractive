# AI for Teamwork — Midjourney Art Direction & Prompt Library

Full photorealistic image set for the AI for Teamwork interactive workbook. Every prompt is an editorial Hasselblad photograph with lens and aspect ratio matched to its placement in the site.

## Visual language (applies to every image)

- **Look:** photorealistic editorial photography — modern Australian workplace, candid not stocky, natural window light, shallow-to-medium depth of field, warm neutral palette with subtle environmental accents of teal `#00C0AF` and cream `#F1EEDE` (a notebook, a chair, a wall panel — never dominant).
- **People:** diverse in age, gender, ethnicity and body type; business-casual; engaged and warm, never posed at camera unless specified. No real or recognisable individuals.
- **Screens:** laptops/monitors show soft abstract UI glow only — no readable text, no real product interfaces.
- **Cameras/lenses:** Hasselblad X2D 100C with XCD lenses for candid/environmental work; Hasselblad H6D-100c with HC lenses for wider set-piece scenes; XCD 120mm macro for detail shots.
- **Aspect ratios:** heroes `21:9` (full-bleed) or `16:9`; two-column concept images `3:2`; card/tile art `4:3`; portrait anchors `4:5`.
- **Suffix used throughout:** `--style raw --v 7`. Add `--no text, watermark, logo` if artefacts appear.

Naming: save selected outputs as `assets/img/<id>.jpg` using the IDs below.

## Generation workflow

1. Run heroes first (they set the visual register); pick one from each grid of four, then `--sref` the chosen hub-hero image URL on subsequent batches for palette/light consistency.
2. Vary + upscale selections; export JPG, compress to ~200–350KB for web (heroes up to ~500KB).
3. Watch-fors: readable screen text (reroll or add `--no text`), extra fingers on hand-detail shots, accidental real-brand furniture/logos, and over-teal grading — the accent should stay environmental, not a colour wash.
4. Total: 44 prompts → 44 selected finals covering every hero, band and activity anchor in the build plan.
